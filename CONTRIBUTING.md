> **Cherry-Social** — Built by Cherry Computer Ltd.  
> We love contributions from the developer community!

---

## 🚀 Getting Started

### 1. Fork & Clone

```bash
# Fork the repository on GitHub, then:
git clone https://github.com/YOUR-USERNAME/Cherry-Social.git
cd Cherry-Social
git remote add upstream https://github.com/Infinite-Networker/Cherry-Social.git
```

### 2. Create a Branch

```bash
git checkout -b feat/your-feature-name
```

### 3. Make Your Changes

Follow our [coding standards](#-coding-standards) and [commit convention](#-commit-convention).

### 4. Submit a Pull Request

Push your branch and open a PR against `main`.

---

## 📐 Coding Standards

- Use **TypeScript** — no `any` types
- Follow **ESLint** rules: `npm run lint`
- Format with **Prettier**: `npm run format`
- Write **tests** for new features: `npm run test`

---

## 📝 Commit Convention

We use [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>(scope): <description>

[optional body]

[optional footer]
```

| Type | Description |
|------|-------------|
| `feat` | New feature |
| `fix` | Bug fix |
| `docs` | Documentation |
| `style` | Formatting, no logic change |
| `refactor` | Refactoring |
| `test` | Tests |
| `chore` | Build, tooling |

## 🐛 Reporting Bugs

Use the [Bug Report template](https://github.com/Infinite-Networker/Cherry-Social/issues/new?template=bug_report.md).

Include:
- OS & browser version
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
